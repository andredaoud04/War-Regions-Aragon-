# Argon Warfront

An independent, single-file, browser-based hexagonal real-time strategy game generated during the Argon War Regions development benchmark.

## Play locally

Download or clone this repository and open `index.html` in a modern desktop or mobile browser. No build step, package manager, or external assets are required.

## Gameplay

- Drag from a blue base to another base to deploy your current troops.
- Capture neutral and enemy bases, reinforce your own, and control territory.
- Different base types produce infantry, tanks, artillery, helicopters, or gunboats.
- Terrain and unit movement types affect valid routes.
- The game includes five campaign sectors, three AI difficulty settings, permanent upgrades, and local browser save data.

## Controls

- **Mouse/touch:** Drag from one base to another.
- **Zoom:** Mouse wheel, pinch (where supported), or the in-game zoom controls.
- **HUD:** Restart, speed toggle, and Command HQ.

## GitHub Pages

To host the game through GitHub Pages: repository **Settings → Pages → Build and deployment → Deploy from a branch**; choose `main`, folder `/(root)`, then save. GitHub will provide the live site URL once the deployment is complete.
